低价年付 VPS 大致分三层。

## 年付便宜不等于总成本低

### 首单价和续费价经常不是一回事

低价年付最常见的玩法是首年特价、次年原价。判断方法很直接：看优惠码名字里有没有 `RECURRING` / `Recur` 这类字样。带循环字样的码，续费时同样打折；不带的那种只影响首单。DMIT 目前在多个来源里被反复引用的几个码都属于循环折扣，这一点比"首年立减"实在得多。

### 流量超了之后会发生什么

这是便宜年付最容易忽略的一栏。有些商家超量直接停机，或者按 GB 计费，账单在你没注意的时候长出来。

DMIT 的处理方式是不停机、降速跑。Tier 1 系列的 WEE 在常规流量用完后，香港和日本机房限速 50Mbps、洛杉矶限速 100Mbps，继续不限量使用；往上几档分别是 100Mbps、200Mbps、500Mbps 直到 1Gbps。洛杉矶 AS3 的 Premium 和 Eyeball 系列超量后降到 4—10Mbps 不限量，速度难看，但至少机器不会掉线。

对一个挂着的小站来说，超量后能继续跑，比"每月精确控流量"要省心。

### 线路差一档，体感差很多

DMIT 按网络划了三条产品线，名字容易看混，实际区别是这样的：

- **Tier 1（T1）**：国际 BGP，没有针对中国大陆做专门优化，胜在带宽大、价格低。香港和日本机房本身离得近，延迟基线不差。
- **Eyeball（EB）**：三网回程走 CMIN2，电信去程在 AS9929 与 AS58807 之间做负载分配，联通主要走 AS9929，移动主要走 AS58807。
- **Premium（Pro）**：CN2 GIA（AS4809）。电信去程走 AS4809，联通去程直连 AS4837，移动去程经香港移动 AS58453，三网回程都是 AS4809。

一个能直接看出差别的例子：洛杉矶 AS3 里 Pro.STARTER 和 EB.STARTER 月付都是 34.90 美元，硬件同为 2 核 2GB / 80GB SSD / 10Gbps 端口，但 EB 给 5TB 月流量，Pro 只给 3TB。同等价位下 EB 用流量换线路档次，移动和联通用户的实际体感往往不吃亏。

### IP 和售后也是成本

超低价年付机最常见的突发状况是 IP 被墙。下单前值得花两分钟确认商家的换 IP 政策和工单响应情况，别等出事再查。这一条跟价格无关，但决定了你的 36.9 美元是不是白花。
